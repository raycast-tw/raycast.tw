Raycast 是通往電腦上一切的快捷方式。你可以開啟 app、尋找檔案、控制日常工具、詢問 AI，還能自動處理重複工作，全程不必打斷專注狀態。

我知道這聽起來很多。不過，只要給我十分鐘，我會帶你看完核心功能，也說明如何判斷哪些功能適合放進自己的設定中。它們將改變你往後使用電腦的方式。開始吧！

本文翻譯自 Thomas Paul Mann 在 X 發表的 〈Getting Productive with Raycast〉。

從第一組快捷鍵開始

Raycast 的所有操作都從鍵盤快捷鍵開始。我使用 ⌘ Space，讓它取代 Spotlight，也早已成為肌肉記憶。每當需要做什麼，我就按下快捷鍵開啟 Raycast，再輸入想執行的動作。

無論是啟動 app、尋找檔案、進行計算、查看行事曆，或執行 command，你都不必記得它藏在哪裡，只要搜尋想做的事即可。

接下來幾天，試著先從 Raycast 開始，而不是伸手去找 Dock、選單列或瀏覽器。光是這個改變，就是養成啟動 Raycast 習慣最快的方法。

先搜尋，再加快捷鍵

你在 Raycast 裡做的大多數事情，都以 command 的形式提供。Command 可以開啟內容、搜尋服務、控制 app、轉換文字，甚至完成整套工作流；它們全部都能從 Root Search 找到。

當你發現自己經常使用某個 command，先選取它，再按 ⌘ K 開啟 Action Panel，接著就能設定一組 hotkey，從任何 app 直接執行。例如我把 ⌃ ⌘ Space 指派給 emoji 搜尋；它能從任何 app 開啟、依名稱找到 emoji，並直接插入正在輸入的內容中。

複製過的內容，再也不會弄丟

Clipboard History 會保留你複製過的文字、連結、圖片、顏色與檔案，方便日後再次使用。你不必再小心記著剪貼簿現在放了什麼；對我來說，它真的就像第二大腦。

我建議替這個 command 設定 hotkey。我使用 ⌥ V，工作時可以連續複製多個項目，需要時再按快捷鍵找出正確的那一筆。這也讓你能輕鬆找回今天稍早、甚至幾週前複製過的連結、圖片或文字。

把日常工具帶進 Raycast

Extensions 能把 Raycast 與你已經在用的工具連接起來。不必開啟個別 app，你就能管理 Linear issues、控制 Spotify 音樂、查看 Google Calendar、處理 GitHub pull requests，以及完成更多工作。

開啟 Store，先為每天會用到的一兩項服務安裝 extensions。它們的 commands 會和 Raycast 內建指令一起出現，讓你搜尋動作時，不必先思考它屬於哪個 app。

留意那些平常需要開啟網站、找到正確頁面，再點過幾層選單才能完成的工作流。這類流程通常最適合優先搬進 Raycast。

如果 Store 裡還沒有需要的工作流，你也可以打造自己的 extension。先在 AI Chat 裡說明整個流程，再請 AI 協助你一次完成一個 command。

重要地點與資訊隨手可得

Quicklinks 能把網站、檔案、資料夾與搜尋變成 commands。你可以替反覆造訪的地方建立 Quicklink，例如專案儀表板、repository、客戶紀錄或內部文件。

Quicklinks 也能接收輸入內容。它可以詢問搜尋關鍵字、使用另一個 app 中選取的文字，或插入目前的剪貼簿內容。你不必先開啟網站再慢慢導覽，只要直接告訴 Raycast 想抵達哪裡。

Snippets 對文字提供了類似的能力。它能保存 email 回覆、會議連結、地址、程式碼、commands，以及任何你厭倦手動輸入的內容。替 Snippet 設定簡短關鍵字，在任何 app 輸入後，Raycast 就會把它展開成完整文字。我的幾個例子：

  • 用 @@ 輸入主要 email 地址。
  • 用 !phone 輸入手機號碼。
  • 用 !today 輸入今天的日期。

一個實用習慣，是主動留意重複。當你心想「我之前開過這個」或「我之前寫過這段」時，就把它變成 Quicklink 或 Snippet。

不離開工作現場就能問 AI

只是想快速問個問題時，開啟 Raycast、輸入問題，再按 Tab。需要較長的對話時，則開啟 AI Chat；你可以繼續追問、加入附件、切換模型，也能回到先前的對話。

我把 ⌃ J 指派給 AI Chat，因為整天都會用到。只要這一組快捷鍵，就能開始較長的對話，或接續上次停下來的地方。

處理小幅修改時，我會使用 Quick Fix。輸入或選取文字後，連按兩次右側 Shift，Raycast 就會直接在目前 app 修正拼字與文法，不必複製、貼上，也不用切換視窗。

你也可以為經常重複使用的 prompt 建立 AI Commands。選取一段文字後執行 command，就能摘要、翻譯、review 程式碼、改善文句，或直接取代原文。一個好的 AI Command 會記住你希望例行工作如何完成。

用說的，不必打字

Dictation 能在任何可以輸入文字的地方，把語音轉成整理過的文字。想讓它最好用，請設定全域 hotkey；我使用 ✦ Space，而 ⌃ M 也是不錯的預設選擇。按下快捷鍵後自然說話，再按一次，就會把結果插入目前的 app。Raycast 會自動移除贅詞，並修正標點、大小寫與文法。

Dictation 也會依照你正在輸入的地方調整結果：訊息可以保持簡短口語，email 則會加入段落、標點與結尾。你也能把人名、產品術語與專業用語加入詞彙庫，提升轉錄正確度。

我很常用 Dictation 來輸入 AI prompt。用說的更容易補足脈絡、解釋需求，也能先把想法完整說出來，不必太早開始修改。我也會用它撰寫訊息與初稿，或在靈感消失前先記錄下來。

讓 AI 使用你的工具

AI Extensions 能讓 Raycast AI 操作你已安裝的 extensions。在 AI Chat 或 Quick AI 輸入 @，選擇一個或多個 extensions，再用自然語言說明想達成的結果。

一般 command 只會執行一個預先定義的動作；AI Extensions 則能在同一個請求裡組合多項工具。例如，你可以請 Calendar 與 Linear 找出明天的空檔，再替最高優先級的 issue 保留那段時間。

Raycast 會自行判斷該呼叫哪些工具、在工具之間傳遞正確資訊，並讓你看見執行中的動作。你不必知道確切的 command，也不必親自完成每個步驟。

你還能為 extensions 加入自訂指示。例如，告訴 Calendar 不要安排上午十點前的會議，或指定 Linear 預設使用哪個 team。如此一來，是 AI 配合你的工作流，而不是你反過來適應它。

掌控桌面

Raycast 能移動、調整大小並排列視窗，不必另外安裝 app。我使用 ⌃ ⌥ 搭配方向鍵，把目前視窗放到畫面的左半、右半、上半或下半；⌃ ⌥ ↵ 則會將視窗最大化。

這些快捷鍵很容易記住，因為按鍵方向和視窗移動方向一致。先從經常使用的一兩種排列方式開始；如果常把多個 app 放在同一組位置，也可以保存完整 layout，日後用一個 command 還原。

把設定帶著走

Cloud Sync 會讓你打造的 Raycast 設定在各個裝置上保持可用。Quicklinks、Snippets、Notes、AI chats、extensions、themes 與 window layouts，都能跟著你在 Mac、Windows 與 iOS 之間移動。

第一天不必急著設定它。不過，當你在另一台電腦或手機安裝 Raycast 後，請開啟 Cloud Sync，確認熟悉的內容有順利出現。當另一台裝置上的 Snippet、Quicklink 或對話也出現在眼前，Raycast 才會開始像是你自己的設定，而不只是一台電腦上的 app。

養成 Raycast 習慣

第一天不必追求完美設定。當你逐步依照工作方式塑造 Raycast，它會愈來愈有價值。每次發現操作阻力時，問問自己：

  • 我是否一直重複搜尋這個內容？
  • 我是否每天都會開啟同一個地方？
  • 我是否一直輸入相同文字？
  • 我是否不斷重複同一連串動作？
  • 我能否把這項工作說明給 AI 聽？

動手建立任何東西之前，先看看 Raycast 是否已有對應 command 或 extension。有的話就直接使用；如果沒有，先做出能消除阻力的最小工具，例如 Quicklink、Snippet 或 AI Command。若是更特定的工作流，再考慮打造自己的 extension。

簡單總結：你的 Raycast 第一週

你不必一次設定所有功能。先從 ⌘ Space 開始，再逐項加入實用的新習慣：

  • 用 Raycast 開啟 app、尋找檔案、進行計算，以及快速詢問問題。
  • 替 Clipboard History 設定快捷鍵。
  • 寫作時試試 Quick Fix。
  • 設定 Dictation，用說的輸入一則真正的訊息或 AI prompt。
  • 當 Quick AI 的問題愈問愈深入時，把它移到 AI Chat。
  • 替每天使用的工具安裝一個 extension。
  • 把一個重複造訪的地方或一段重複文字，變成 Quicklink 或 Snippet。
  • 若會在其他裝置使用 Raycast，開啟 Cloud Sync，把設定一起帶過去。

接下來，每當發現新的操作阻力，就繼續改善自己的設定。

最好的 Raycast 設定，並不是擁有最多 commands 的那一套，而是能讓你保持專注，並讓電腦彷彿完全依照你的工作方式打造的那一套。
