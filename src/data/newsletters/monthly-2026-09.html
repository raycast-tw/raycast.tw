九月更新：更快、更輕、Send to AI 與 Auto Model

Pedro 帶來九月月報。這個月的重點是讓 Raycast 跑得更快、占用更少資源，另外也加入新的 AI 上下文工具、模型選擇方式與系統指令。

更快、更輕

最近兩個版本都把重點放在記憶體用量與效能：

  • 在 Mac 上，AI Chat、Notes 與 Settings 現在各自在獨立 process 執行。繁忙的聊天或大型筆記不再拖慢 Root Search，關閉後也會釋放所占用的記憶體。Raycast 主程式待機時最多可減少 35% 記憶體用量。
  • Raycast host process 的記憶體用量約減少 50%，每個 extension process 啟動時的記憶體用量約減少 30%。
  • 修正一項會隨著 Raycast 開啟時間愈久而持續增長的記憶體洩漏。
  • File Search 尖峰記憶體用量最多減少 80%，搜尋期間最多減少 95%；搜尋速度最多提升 30%，背景索引也會使用少得多的 CPU。
  • AI request 的資料量變小，讓 local model 回覆簡單訊息的速度更快，簡單請求消耗的 credits 也更少。

把畫面內容傳送給 AI

Mac 新增兩個指令，讓 AI 直接理解你正在看的內容。使用 Send Element to AI 時，把游標移到螢幕上的段落、圖片或按鈕等元素，再按一下就能傳送到 AI Chat；若要分享整個視窗，則可使用 Send Window to AI。

建議替 Send Element to AI 指定像是 ⌘ + ⇧ + 0 的 hotkey，能更快擷取上下文。

更多系統指令（僅限 Windows）

五個新指令讓日常設定都能在幾次按鍵內完成：用 WiFi 與 Bluetooth 管理網路與藍牙裝置；用 Toggle WiFi、 Toggle Energy Saver 與 Toggle Airplane Mode 切換各項功能；也能透過 Toggle Camera Mute 封鎖或恢復所有 App 的相機存取權。替常用指令設定 hotkey，操作會更快。

Auto Model

Auto Model 經過重新設計，現在可以選擇三種模型挑選偏好：

  • Lightweight：回應時間比 Flagship 約少 70%，適合快速提問。
  • Balanced：預設選項，使用的 credits 比 Flagship 約少 70%。
  • Flagship：針對較困難的任務使用能力最強的模型，需要 Pro+ 或 Max 訂閱。

現在也能在 AI Chat 輸入 /usage，或到 Settings 查看 Claude 與 ChatGPT 訂閱用量。

Extension 提供的 AI 模型

Extensions 現在能把自己的 AI 模型帶進 Raycast。從 Store 安裝相容的 extension 並完成設定後，就能在 AI Chat 選擇它提供的模型。

已支援的 extensions 包括 Ollama AI、AI by Vercel、Cerebras、Groq與 LM Studio。開發者可以查看 API changelog，把模型加入自己的 extension。

Projects、Automations 與自有訂閱

上個月介紹的新版 Raycast AI，也一起帶來幾項值得補充的功能。

  • Bring Your Own Subscriptions：在任何 Raycast 付費方案中連接 Claude 或 ChatGPT 帳號，就能在 AI Chat、Quick AI 與 AI Commands 使用訂閱內的模型。可以前往 Settings → AI → Models & Providers 開啟。
  • Projects：把同一主題的對話集中管理。每個 Project 都有自己的記憶，不必每次開始新對話都重新說明；也能指定 Obsidian vault、發票資料夾等 working directory，讓 agent 知道要在哪裡處理檔案。
  • Automations：按照排程執行 prompts，由 agent 在背景處理並把結果加入對話。Raycast 團隊會用它每天早上分類 email、每小時追蹤 open pull requests，並在每天晚上從會議筆記更新 Raycast 的記憶。

iOS：新版導覽

Raycast for iOS 加入可自訂的 tab bar。常用功能可以放在隨手可及的位置，其餘功能集中在 More，並能透過統一搜尋找到 App 內需要的內容。

符合資格的個人方案也能直接在 App 內加購 AI credits，還可以透過 Dictation History 重新查看過去的逐字稿。
