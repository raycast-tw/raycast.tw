四月更新：Raycast 2.0 beta、Windows、iOS 與美國活動

Pedro 帶來等待數月的重要月報：Raycast 2.0 beta 已公開推出，同時 Windows、iOS 與社群活動也都有新的進展。

新版 Raycast 已推出

Raycast 2.0 beta 現在已經公開開放下載試用。這次更新帶來全新的設計、完整的 Dictation 指令、根搜尋中的 File 與 Contacts、Quicklinks 與 Snippets 的標籤功能，以及更多細節改善。

想了解新版 Raycast 的設計與功能，可以閱讀 新版 Raycast 發表文章；如果對背後技術更有興趣，也可以看 新版 Raycast 技術深度解析。

Raycast for Windows

Windows 版這個月加入多個高需求功能，讓日常操作更接近 Mac 版體驗。

  • Hyperkey：把單一按鍵變成強大的快捷鍵修飾鍵，方便觸發獨立快捷鍵。想了解運作方式，可以看 Hyperkey 介紹影片。
  • Custom Themes：可選用現成主題，也能用全新的 Theme Studio 設計自己的 Raycast 外觀。
  • International Keyboard：改善 國際鍵盤支援，也優化 hotkey recorder，讓快捷鍵設定更容易使用與理解。
  • Settings Search：可搜尋 Raycast 設定，快速找到 extensions、commands 與 settings，不必記住每個選項的位置。
  • Bug Fixes & Improvements：完整細節可參考 Windows 更新日誌。
