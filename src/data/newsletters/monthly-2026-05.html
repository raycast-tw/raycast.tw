五月更新：Focus、Color Conversion、Windows Dictation 與 iOS BYOK

Pedro 帶來五月月報：新版 Raycast 推出後，Focus 與 Color Conversion 回到 Mac 和 Windows，Windows 版也迎來 Dictation，iOS 則新增 BYOK 支援。

Focus 回來了

新版 Raycast 上線後，許多使用者都在等待 Focus 功能回歸。現在 Raycast Focus 已經可以在新版 Raycast 使用，協助你封鎖干擾、設定目標與專注時間，並選擇要封鎖或允許的項目。

Focus 目前可在 Raycast v2 for Mac 與 Raycast for Windows 使用。

#f00 轉成 rgb(255, 0, 0)

Color Conversion 也回來了。現在你可以直接在 root search 輸入任何色彩值，並把它複製成另一種格式。

這個小而實用的功能已同時支援 Raycast v2 for Mac 和 Raycast for Windows。

Windows 版 Dictation

新版 Raycast for Mac 推出 Dictation 後，很多人很快就開始詢問 Windows 版何時支援。現在 Raycast for Windows 也可以使用 Dictation，包含 Mac 上同樣的 Dictation Styles、Microphone Priority、push-to-talk 等功能。

你可以從 Dictate command 開始使用，或直接 下載 Raycast for Windows。完整變更可查看 Windows changelog。

iOS 支援 BYOK

Raycast for iOS 現在支援 bring your own key。你可以使用自己的 AI provider key 傳送 AI 訊息，依照自己的 provider 成本使用，不必訂閱 Pro。

還沒試過 iOS 版的話，可以前往 Raycast for iOS。
